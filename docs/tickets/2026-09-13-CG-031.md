# CG-031 — Optional embeddings-based semantic retrieval

Date: 2026-09-13
Status: Planned
Depends on: CG-016, CG-017, CG-020

## Outcome

Upgrade CG-017 lexical retrieval with an opt-in embeddings-based semantic search
over the CG-016 bounded corpus, behind a retrieval `Protocol`. The default
runtime stays lexical, offline and network-free; semantic mode is explicit.
Single-host only: reuse the CG-015 Postgres instance (`pgvector`) or an
in-process persisted vector index. No external managed vector database.

This is a post-v1 job-skill extension (RAG / embeddings / vector search), not a
v1 release requirement. Deterministic analysis never depends on it.

## Files

Planned create:

- `src/changeguard/application/retrieval.py` — extend/define a `Retriever`

- `src/changeguard/adapters/embeddings.py` — provider-neutral async embeddings

Actual files changed by this ticket: none. This backlog document is the only file created now.

## Contract

1. `Retriever` is a protocol; lexical (CG-017) remains the default implementation.
2. Embeddings live behind an async protocol with a disabled/offline adapter that
   returns deterministic fixture vectors without network access.
3. Vectors persist alongside the CG-016 corpus with stable IDs; retrieval returns
   source IDs and byte/line spans reusable by CG-019 citation validation.
4. Top-k with an explicit score threshold; ties broken deterministically by
   source ID so results do not depend on dict/filesystem order.
5. No secrets, tokens or local config paths enter the embeddings input model.
6. Semantic mode is opt-in; absence or failure falls back to lexical, never fails
   deterministic analysis.

## Acceptance criteria

- With no provider configured, retrieval is lexical and makes no network call.
- Offline semantic mode with fixture embeddings returns reproducible top-k across runs.
- Retrieved items carry source IDs and spans usable by CG-019.
- Type-checks against the `Retriever` protocol with a fake semantic retriever.
- No new runtime dependency unless a concrete activation is part of the same reviewed change.

## Non-goals

- External managed vector DB (Pinecone/Milvus SaaS) or a distributed index.
- Re-ranking models, fine-tuned embeddings or hybrid-score tuning platforms.
- Live embedding cost/eval; that reuses CG-021 optional live mode.

## TDD loop

5. Add a fallback test: semantic disabled → lexical results, no network.
