# CG-034 — Streaming advisory output over SSE

Date: 2026-09-13
Status: Planned
Depends on: CG-014, CG-020

## Outcome

Stream optional AI advisory enrichment token-by-token from the CG-014 endpoint
using Server-Sent Events (SSE). Deterministic findings are always returned in
full and never depend on streaming. Streaming is opt-in and degrades gracefully
to a single final payload when AI is disabled.

This is a post-v1 job-skill extension (streaming LLM UX), not a v1 release
requirement. It supersedes CG-018's "streaming responses" non-goal.

## Contract

1. The SSE stream emits deterministic findings as the first event(s), then advisory
   tokens, then a terminal `done` event.
2. With AI disabled, the stream emits deterministic findings plus an explicit
   `ai_unavailable` event and closes cleanly.
3. Advisory tokens remain untrusted until CG-019 validation; a final validated
   advisory event supersedes streamed draft tokens if validation rejects content.
4. Client disconnect cancels the provider stream and releases resources.
5. The same analysis is also available as a non-streaming JSON response (CG-014).

## Acceptance criteria

- Event order is deterministic: findings before advisory before `done`.
- Disabled-AI request yields findings + `ai_unavailable`, no provider call.
- A simulated client disconnect cancels the upstream token iterator.
- Streamed advisory content that fails CG-019 is not presented as supported.

## Non-goals

- WebSocket transport or bidirectional protocols.
- Frontend/client implementation.
- Partial-result persistence; CG-015 owns durable reports.
