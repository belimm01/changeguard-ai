# CG-007 — Define v1 system boundary, scope, and threat model

Date: 2026-09-10
Status: Done
Depends on: CG-006

## Outcome

The project has an explicit v1 advisory boundary: ChangeGuard reads GitHub pull-request metadata and file content, runs deterministic checks plus later cited recommendations, and returns evidence-backed advice without merging, blocking, approving, or executing repository code.

## Design principles

- A system boundary names trusted components, untrusted inputs, and side effects.
- A threat model is useful only when it drives implementation constraints and tests.
- Scope control is a security feature: unsupported inputs must be reported as unsupported or partial, not silently treated as safe.

## Files

Modify existing:

- `docs/adr/0001-system-boundary.md` — fill the existing empty ADR with the boundary decision.
- `docs/threat-model.md` — fill the existing empty threat model with assets, trust boundaries, threats, and mitigations.

## Acceptance criteria

- `README.md`, `docs/adr/0001-system-boundary.md`, and `docs/threat-model.md` all state that output is advisory and may be wrong.
- The docs explicitly prohibit auto-merge, auto-approval, auto-blocking, and execution of repository code in v1.
- Untrusted inputs are named: GitHub API payloads, file paths, patches, repository file content, PR comments, issue text, and future LLM/tool output.
- Trusted inputs are named: service configuration, pinned application code, injected credentials, and operator-controlled deployment settings.
- Required mitigations are listed for path traversal, symlinks, oversized files/diffs, credentials in logs, stale base/head SHAs, prompt injection in repo content, API pagination truncation, and unsupported formats.
- Unsupported coverage is defined as `partial` or `unsupported`, never `safe`.
- Existing empty ADR/threat-model files are filled; no new duplicate architecture documents are created.

## Non-goals

- No GitHub API client, FastAPI endpoint, database, LLM, deployment, or new deterministic rule.
- No formal STRIDE matrix if a simpler threat table covers the concrete risks above.
- No claim that the tool enforces repository policy.
